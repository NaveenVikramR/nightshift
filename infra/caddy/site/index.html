Nightshift

Checking status…

Voice on-call & security copilot · MCP server

Ask “what's wrong?” at 3 a.m. Get the answer, not a dashboard.

Nightshift is a self-hosted MCP server that tells you what's wrong in production, why, and fixes it only after you say yes.

How it works

  1. 1 An alert fires

    Prometheus and Alertmanager spot errors, latency, a failing provider or a security spike.

  2. 2 Your phone buzzes

    “Critical: high error rate on payments API. Ask Alexa: what's wrong?”

  3. 3 “What's wrong?”

    A grounded diagnosis from evidence: the Razorpay breaker opened, errors at 45%. Never a guess.

  4. 4 “Fail over?” — “Yes.”

    Two-phase confirmation, then a measured result: errors 45% → 0.5%.

Claude Code:

claude mcp add --transport http nightshift https://<this-host>/mcp --header "Authorization: Bearer <your-token>"

Tokens are issued per person (viewer or responder). Testing tokens for judges are in the submission.

Safe by design

  • Two-phase actions. Prepare, hear what will change, say yes, then it runs once.
  • Allowlisted. Only fail over, roll back or restart. Scans only configured targets.
  • Grounded. Deterministic rules over evidence; weak evidence is said out loud.
  • Untrusted text is data. Alert and commit text is quoted, never obeyed.
  • Audited. Every call is recorded: who, what, when, outcome.
